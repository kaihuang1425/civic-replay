## 作品摘要

Civic Replay 是一個**公共服務情境預演工具**。政府在政策或服務上線前，輸入流程、規則與限制，系統會模擬不同居民實際辦事的過程，找出卡關、資格衝突、文件不足或數位障礙，並比較修改前後結果，讓問題在真正影響民眾前先被發現。

目前展示版以豪雨情境示範居民收不到通知、無法自行移動與需要家人代辦等問題。加入協助措施後，可再次預演並比較結果。完整資格與必備文件驗證仍是後續工作；現有判定範圍見[系統架構](ARCHITECTURE.md)。

## OpenAI 挑戰說明

目前預設透過 Ollama 使用 OpenAI 的 `gpt-oss:120b-cloud`，用於生成服務流程，以及預演中的文字理解、文件準備難度與原因說明。可明確判斷的居民條件由規則引擎處理。

程式尚未直接串接 OpenAI API。參加的挑戰填寫 OpenAI；實際採用的技術以上述說明為準，不能把已申請 API 額度寫成已完成 API 串接。挑戰資格仍以主辦方審查為準。
